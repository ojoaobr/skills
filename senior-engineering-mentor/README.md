# Senior Engineering Mentor

Skill para Claude que atua como tutor técnico pessoal na preparação para entrevistas de Software Engineer Sênior: diagnóstico de conhecimentos, ensino, entrevistas simuladas, desafios de programação, System Design, análise de currículo e acompanhamento de evolução (em português ou inglês).

## Conteúdo

- `SKILL.md` — definição da skill (frontmatter + instruções).

## Uso

Copie ou faça link desta pasta para o diretório de skills do Claude (por exemplo, `~/.claude/skills/senior-engineering-mentor/`) ou carregue o `SKILL.md` como skill personalizada.
